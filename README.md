# Basic Calculator

A lightweight, browser-based calculator for performing addition, subtraction, multiplication, and division on two numbers. The project is a single HTML file with its styles and JavaScript included; it requires no dependencies or build tools.

## Features

- Four basic arithmetic operations on two numbers
- Clear feedback for missing or invalid numbers and division by zero
- Responsive layout for desktop and mobile screens
- Keyboard shortcuts for operations and clearing the calculator

## Getting started

### Run locally

Clone the repository and open `index.html` in a modern web browser:

```sh
git clone https://github.com/VoidLance/course-files-javascript-basiccalculator.git
cd course-files-javascript-basiccalculator
```

Open `index.html` directly, or serve the project with any static file server. No package installation or build step is needed.

### Use the calculator

1. Enter a number in each input field.
2. Select **+**, **−**, **×**, or **÷** to see the result.
3. Select **C** to clear both inputs and reset the display.

Keyboard shortcuts: `+`, `-`, `*` or `x`, and `/` perform the corresponding operation; `C` or `Escape` clears the calculator. Press `Enter` to repeat the last operation.
